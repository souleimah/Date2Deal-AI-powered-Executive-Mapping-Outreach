# Frontend Directory

This directory contains the React + TypeScript frontend for Date2Deal.

## Structure

- `dashboard.tsx` - Executive dashboard with org chart
- `ai-chat-page.tsx` - AI chat interface for contact messages
- `company-data-service.ts` - Company data service
- `components.json` - Shadcn/UI components configuration

## Setup

```bash
cd front
npm install
npm run dev
```

The app will be available at: http://localhost:5173 (default Vite dev server port)

## Tech Stack

- React
- TypeScript
- TailwindCSS
- Shadcn/UI
